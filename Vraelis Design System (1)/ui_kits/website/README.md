# Vraelis website UI kit — v2 (industrial)

Single-page marketing site for Vraelis. Light mode, hard edges, considered typography, one warm accent. Built to look nothing like the prior dark-cinematic system.

## Open

`index.html` — opens the full site.

## Components

| File | What it is |
|---|---|
| `App.jsx` | The full page, composed from the parts below |
| `Nav.jsx` | Top nav — wordmark, subdomain links (chat, platform), CTA |
| `Hero.jsx` | Display headline + product spec block + product mock |
| `ManifestoBlock.jsx` | Editorial paragraph — what Vraelis is, in plain English |
| `FeatureRow.jsx` | Reusable feature row: large product photo, number, headline, paragraph, spec list |
| `Spec.jsx` | Two-column technical specifications block |
| `WaitlistBlock.jsx` | Plain form on bone background |
| `SiteFooter.jsx` | Minimal footer — three columns, no community CTA |

## What's new (different from v1)

- Light mode (warm off-white `#F4F1EB`)
- Hard 2–4px corners, no pill shapes
- Inter Tight + JetBrains Mono — no Geist
- Burnt sienna `#A03828` as the only accent — no violet
- No backdrop blur, no glow halos, no gradient text
- "Spec callouts" replace the mono-uppercase eyebrow as the brand's signature typographic detail
- Photography is real product / honest stock, not atmospheric mood shots
